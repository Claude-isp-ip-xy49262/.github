<h2>一、先给手上的任务归个类</h2>
<p>归类只需要两个维度：单次任务持续多久，以及执行期间有没有人盯着。两个维度交叉出四种典型形态，对应的配置要求和容错策略完全不同。归类错了，后面所有优化都在错的方向上使劲。</p>
<h3>按持续时间分：短任务和长任务的分界线在四小时</h3>
<p>四小时以内，一次失败重来的成本可以接受；超过四小时，重来一次就是半天，收益全没了。这条线决定了你要不要做断点续跑，而不是要不要换线路。</p>
<h3>按值守方式分：有人盯和没人盯</h3>
<p>有人盯的时候，掉线五分钟内能被发现，恢复也快；没人盯的时候，掉线意味着任务彻底停在那里，直到下一次有人打开电脑。夜间任务几乎全部属于后者，这也是它对出口稳定性要求更高的原因。</p>

<h2>二、场景一：整夜跑的长任务</h2>
<p>这类任务是独享固定出口最对口的场景。原因不复杂：共享出口在夜间的使用者数量虽然少，但只要有一个人挂在上面跑长连接，你的连接就可能被挤掉。单账号独享一条地址，挤掉你的只可能是自己。</p>
<h3>夜间第一小时是观察窗口</h3>
<p>任务启动后的第一个小时最关键。把这段时间的连接日志单独存下来，记三项：建立连接耗时、是否有中途重连、最后一次心跳的响应时间。第一小时干净，后半夜出问题的概率明显低；第一小时就有一次重连，别抱侥幸。</p>
<h3>半夜被挤下线的典型特征</h3>
<p>被挤掉和线路故障的表现不一样。被挤掉通常是连接被对端主动关闭，本地日志里出现的是重置而不是超时；线路故障更多表现为持续超时、心跳全部无响应。看清是哪种，才知道该找谁。</p>

<h2>三、场景二：凌晨定时触发</h2>
<p>定时任务看起来最简单，实际上坑最多。因为它是无人值守的，失败了你也不知道，只有第二天看到结果缺了一块才反应过来。三个细节值得提前配好。</p>

<h3>触发窗口别卡在整点</h3>
<p>整点是全网请求最密集的时刻，跨境线路在这个点上的抖动往往是平峰的几倍。把触发时间挪到 03:17 这类非整点，任务本身的耗时不长，但成功率的差别是实打实的。错开五到十分钟就够了。</p>
<h3>重试要带幂等</h3>
<p>无人值守的任务必须假设第一次会失败。重试两次、间隔逐步拉长，同时保证重复执行不会产生重复结果——这需要在任务开始前先查一次已完成标记，而不是直接往下跑。</p>
<h3>结果要能自证</h3>
<p>任务跑完写一行日志：开始时间、结束时间、处理条数、出口地址。四个字段足够你在第二天判断这次是跑完了还是中途停了。没有这行日志，你只能靠翻聊天记录回忆。</p>

<h2>四、场景三：白天有人盯的交互会话</h2>
<p>白天用的场景对出口的要求和夜间不同。夜间怕的是被挤掉，白天怕的是一顿一顿。两者其实是同一个问题的两面：连接是否被别的会话争抢。</p>
<h3>体感指标看三项就够</h3>
<p>首字出现的时间、长回复是否中途停顿、切换会话时是否需要重新加载。三项都在可接受范围内，说明这条出口对你的日常使用是够的。不必去追那些更复杂的指标，日常使用感受不到。</p>
<h3>多端并行按端配线</h3>
<p>笔记本加台式机同时用，就是两个会话。要么给每个端配一条地址，要么接受其中一端偶发被顶掉。折中方案是把非主力端放到另一条 ISP 线路上，两条线各管一端，互不干扰。</p>

<h2>五、哪些情况并不适配独享固定出口</h2>
<p>不是所有需求都该上这套配置。下面三种情况，用独享固定出口要么是浪费，要么方向就不对。</p>
<h3>账号只有一两个、使用时间很零散</h3>
<p>一天只用半小时、还集中在下午，共享线路被挤的概率本来就低。这时候按小时计费的方案更划算，付整月的独享费用换来的稳定性，你其实感受不到。</p>
<h3>需要频繁切换地区</h3>
<p>固定出口的价值在于不变，如果你的业务需要按市场切换地区，那要的是「可指定地区的多条出口」，而不是「一条固定出口」。这两件事经常被混为一谈，买错了很难受。</p>

<h2>常见问答</h2>
<h3>独享出口是不是就不会掉线了？</h3>
<p>答：不是。独享排除的是「被别人挤掉」这一种原因，排不掉上游线路维护、本地网络波动、客户端自身超时设置不当。它能显著减少掉线概率，但做不到零。</p>
<h3>夜间任务失败了，第二天怎么快速定位？</h3>
<p>答：看三样东西：任务日志里的最后一条记录时间、连接日志里是超时还是重置、以及当时的出口地址。三者一对，基本能区分是本地、线路还是对端的问题。</p>
<h3>一条固定出口能同时跑几个夜间任务？</h3>
<p>答：建议一个。两个任务并行会让并发翻倍，被重置的概率上升，而且日志混在一起难以排查。确实要多任务，按任务数配地址，别在一条线上排队。</p>
<h3>按小时计费和包月，夜间任务该选哪个？</h3>
<p>答：看每月实际跑多少晚。连续跑二十晚以上，包月通常更省；只在月底集中跑三五晚，按小时更合适，而且淡季可以停掉不花钱。</p>
